# Sơ Đồ Hoạt Động (Activity Diagrams)
Lưu trữ sơ đồ luồng hoạt động tổng thể và các phân hệ:
- `activity-tong-the.drawio`: Luồng 10 bước tổ chức ĐATN từ mở đợt đến xuất biên bản bảo vệ.
- `activity-phan-cong-gvhd.drawio`: Thuật toán phân công bán tự động ưu tiên NV1, GPA và Quota.
- `activity-cham-diem.drawio`: Luồng chấm điểm Hội đồng và tổng hợp điểm 40/60.
