# Mapping implementation hiện tại

Có **102 Prisma models**, khác số 99 trong blueprint cũ. Danh sách đầy đủ FK/PK/unique/enum tại [schema-map.json](evidence/schema-map.json); CHECK/trigger nằm trong 27 migration hiện hành, không được thay đổi bởi seed.

Thứ tự seed: danh mục/quyền → học kỳ/đợt/mốc/grant → roster/quota → đăng ký/nguyện vọng → plan/phân công chính thức → topic/đồng thuận → nhóm duyệt/membership → proposal/version/review/decision/comment → finalization/dossier/PDF/receipt/history → plan/period/required-student/obligation → task/submission/upload/asset/review/history → họp/đánh giá → policy TEST/rubric/room → producer UC17–20 → UC21 (BLOCKED) → UC22–25 (chưa thực thi ghi).

Bảng workflow bổ sung revision, binding và lịch sử; không suy luận trạng thái chỉ từ bảng legacy. SubmissionFile/TaskReview có 0 bản ghi vì consumer hiện tại đọc SubmissionAsset/ProgressReview. CommitteeStudent có 0 vì chưa có lịch UC21, không thay thế DefenseCommitteeAssignment đã tạo ở UC19.
